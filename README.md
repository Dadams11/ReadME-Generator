# Professional README Generator

## Description
This application generates a high-quality, professional README file directly from the command line. The user answers a series of prompts using Node.js and the Inquirer package, and the application dynamically creates a formatted README.md file.

This tool helps developers save time when starting new projects by automatically generating important documentation sections such as installation instructions, usage information, licensing, and contact information.

## Installation
To run this application locally, follow these steps:

Clone the repository:
```
git clone https://github.com/Dadams11/ReadME-Generator.git
```

Navigate to the project directory:
```
cd ReadME-Generator
```

Install the required dependencies:
```
npm install
```

## Usage
Run the application using Node.js from the command line:

```
node index.js
```

You will be prompted with a series of questions about your project including:

- Project title  
- Description  
- Installation instructions  
- Usage information  
- License  
- Contribution guidelines  
- Test instructions  
- GitHub username  
- Email address  

After answering the prompts, a professional README.md file will be generated automatically.
